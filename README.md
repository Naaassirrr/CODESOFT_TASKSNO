## 📂 Projects

### 1. 🚢 Titanic Survival Prediction

**Folder:** `Titanic-Survival-Prediction`

A machine learning project that predicts whether a passenger survived the Titanic disaster based on passenger information such as age, gender, passenger class, and other relevant features.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* Matplotlib

**Key Features:**

* Data cleaning and preprocessing
* Exploratory data analysis
* Visualization of survival patterns
* Machine learning model training
* Survival prediction
* Interactive Streamlit application

**Model Performance:**

* Accuracy: approximately **80.45%**

---

### 2. 🎬 Movie Rating Prediction

**Folder:** `Movie-Rating-Prediction`

A machine learning project that predicts movie ratings using information such as year, duration, genre, votes, director, and actors.

**Technologies Used:**

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit

**Key Features:**

* Data cleaning and preprocessing
* Feature engineering
* Categorical feature encoding
* Model training and evaluation
* Movie rating prediction
* Interactive Streamlit application

**Models Evaluated:**

| Model             |    MAE |   RMSE | R² Score |
| ----------------- | -----: | -----: | -------: |
| Linear Regression | 0.6253 | 0.9213 |   0.1270 |
| Random Forest     | 0.4112 | 0.7919 |   0.3552 |

**Best Model:** Random Forest

## 🚀 How to Run the Projects

### 1. Clone the Repository

```bash
git clone https://github.com/Naaassirrr/CODESOFT_TASKSNO.git
cd CODESOFT_TASKSNO
```

### 2. Install Required Libraries

Navigate to the project folder you want to run and install its requirements:

```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit Application

For projects containing a Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.
